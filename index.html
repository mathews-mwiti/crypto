Bot structure

        Your code must return an object with:
        
    
          
  • name — display name
    • 
          
  • params — default numeric/boolean inputs (editable in the sidebar & optimizer)
    • 
          
  • setup(d, p) — runs once; precompute indicators and return them. Arrays whose values sit near price get drawn on the chart.
    • 
          
  • onBar(ctx, ind, p) — runs at every candle close
    • 
        

        
Data d

        d.time d.open d.high d.low d.close d.volume (arrays)
        
Context ctx

        
    
          
  • ctx.i bar index, ctx.time, ctx.open/high/low/close/volume
    • 
          
  • ctx.position 1 long · −1 short · 0 flat
    • 
          
  • ctx.entryPrice, ctx.barsInTrade, ctx.equity, ctx.cash
    • 
          
  • ctx.state — your own scratch object
    • 
          
  • ctx.long(opts), ctx.short(opts), ctx.flat()
    • 
          
  • opts: {sl, tp} prices or {slPct, tpPct}, {size: 50} % equity
    • 
          
  • ctx.setStop(price), ctx.setTarget(price) — move stops (trailing)
    • 
          
  • ctx.log(msg) → Log tab
    • 
        

        
Indicators ta.*

        sma ema wma rma(src,n), rsi(src,n), macd(src,f,s,sig)→{macd,signal,hist}, bb(src,n,k)→{upper,mid,lower}, atr(h,l,c,n), stoch(h,l,c,n,d)→{k,d}, adx(h,l,c,n), vwap(h,l,c,v), supertrend(h,l,c,n,m)→{line,dir}, highest lowest stdev roc(src,n), crossover(a,b,i) crossunder(a,b,i)
        
Tips

        
    
          
  • Indicators are NaN during warm-up — comparisons with NaN are false, so signals wait automatically.
    • 
          
  • Only read [i] or earlier — never [i+1].
    • 
          
  • Ctrl/⌘ + S saves & validates.
